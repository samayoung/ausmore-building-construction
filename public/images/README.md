# Image system

Drop real files here using these exact names. They replace the placeholders automatically, no code changes needed.

- `logo/ausmore-logo.png` company logo (optional, falls back to text wordmark)
- `hero/hero-main.jpg` hero background (landscape, 2400px wide)
- `about/about-main.jpg` about section image
- `projects/project-church-latter-day-saints.jpg` + `-2.jpg`, `-3.jpg` for the gallery
- `projects/project-judges-quarters.jpg` + `-2.jpg`, `-3.jpg`
- `projects/project-church-renovation.jpg` + `-2.jpg`, `-3.jpg`

To add a project, add an entry in `src/data.js`.
